# Call Bridge — Experimental Reconstruction

A standalone Python/MySQL/Kafka experimental reconstruction of a privacy-preserving call-routing architecture for last-mile delivery operations. This is **not** the original proprietary production Java implementation.

This repository is being prepared to accompany the IEEE Software manuscript **“Routing Delivery Calls with Reusable PINs.”**

## Evidence boundaries

- The manuscript reports 88 Google Cloud application checks.
- The source package currently available includes separate **local** quick-run and final-smoke validation results, **not** the complete original evidence for those 88 checks.
- Do not interpret local validations as production throughput, reliability, or telecom performance measurements.
- Synthetic participants and timestamps were used in reconstruction experiments.
